# M5–M8 前端操作与技术验证

## 入口与操作

- 发货管理新增“领星单据与分配”“物流与交接”“报关与 9810”“批次归档”；费用对账位于主导航。周批次选择分组后可进入费用对账及完成检查与归档。
- 每项记录先选择已复核来源与箱范围建立草稿，再按“来源与范围、业务资料、检查与处理、附件与历史”处理。报关默认选择同一目的国家的箱，主体、申报方式、币种及跨国依据须人工核对。
- M5 支持准备与实际商品、组合子件、逐单或逐箱辅料、外部多单分配和取消凭据。M6 支持原始 PDF 箱唛、重量、线下复核与按箱交接；新增交接须使用“提交本次实际交接”，普通草稿保存保留待提交交接内容。
- M7 分别使用“登记报关结果”“登记 9810 结果”提交外部事实；普通草稿保存保留尚未登记的结果填写。七页资料生成、下载、复核后再生成 9810 填写核对清单；模板、反馈和提交版本限定本组记录。
- M8 标准 XLSX 先展示预览，确认后加入费用行并保存。分摊与回填选择具体的“准备单 · 外部单号”；空值、零、退款及补账分别保留。归档显示当前阻塞项与历史文件，失效文件标记为历史版本。
- 附件先在本记录“附件与历史”上传，再回业务资料选择。领星创建、分配、发货及费用修改继续由人员在外部系统操作。

## 错误与版本

- 所有修改附带预期版本；同一请求失败重试保留原操作编号。读取冲突后的最新版本时保留本地填写内容。
- 有未保存内容时关闭向导或离开页面会提示，提交期间防止重复操作。取消记录只读。
- 查询失败可重试；结果登记、来源失效、文件生成失败和文件失效分别展示。历史文件及操作记录保留用于追溯。
