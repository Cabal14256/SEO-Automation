# 历史计划索引

本目录保留早期实施方案和阶段任务计划，便于追溯设计与业务决策。文件中“当前”“未实现”“待确认”等表述对应编写当时，不能直接用于判断现状；旧周范围、M3 实物箱门槛及外部系统写入设想尤其需要核对后续变更。

现行入口为[实现状态](../development/implementation-status.md)、[业务规则](../business/rules.md)、[接口导航](../README.md#接口契约)和[运行维护](../operations/runbook.md)。第三方业务数据当前仅做只读查询，外部操作由人员执行。

| 历史文档 | 保留目的 |
| --- | --- |
| [原始实施方案](plans/original-implementation-plan.md) | 整体业务目标和技术栈重设计背景 |
| [详细开发计划](plans/development-plan.md) | 阶段拆分、任务安排和早期验收设计 |
| [T12 与 M2 计划](plans/t12-m2-plan.md) | 只读同步、核对、编码和制表设计 |
| [M2／M3／M4 拆分计划](plans/m2-m3-m4-plan.md) | 独立工作任务的拆分背景 |
| [M3 计划](plans/m3-plan.md) | 历史实物箱流程和兼容设计；不是新发票前置条件 |
| [M4 计划](plans/m4-plan.md) | 首期丰信 B2B 文件生成方案 |
| [M5–M8 计划](plans/m5-m8-plan.md) | 后续履约、交接、报关、费用和归档的设计范围 |

归档不删除历史决策，也不表示其中全部目标已经实现。原始业务文件、研究和验收证据仍按[隐私规则](../publishing/privacy.md)受控保存，不因文档归档而成为可发布附件。
