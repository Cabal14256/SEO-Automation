# 发票箱规取数与人工修改

2026-10-24 补充：本文下文的“箱规”主要指重量和长宽高；发票默认申报数量另绑定领星本地产品详情 `cg_box_pcs`（每箱包装件数）。每个货箱编号仅输出一个代表产品，按 MSKU、FNSKU、SKU 固定排序取首个；单价取其 Listing 普通售价的 20%，四舍五入两位，无需人工确认价格。件数箱规无效或缺失时，申报数量回退箱内所有产品实际数量之和；混装及箱规与实际不符时，导出后在 Excel 修改。实际商品总量、发货与下游记录仍保留原值。售价及箱规来源随单据修订保存，不由客户端提交；旧已生成文件保留原规则。

更新：2026-10-23（`Asia/Shanghai`）。本页是当前规则，替代早期计划中“发票生成必须完成 M3 实物整组确认”及“人工实测只能留差异、最终仍采用领星值”的要求。

当前流程为：领星只读同步 → M2 核对商品数量、实际箱归属与箱序并分配箱码 → 在发票中检查或修改箱数据 → 保存、校验、生成及复核。工作区不再提供实物箱确认步骤。M2 身份、数量守恒、箱归属、箱序和箱码校验继续执行。

新建单据从 M2 绑定的领星逐箱快照获取 PO、毛重、长宽高及单位，在单据来源快照中保存自动取值和原始值。毛重采用 KG，长宽高采用 CM；KG/LB、CM/IN 以十进制精确换算，使用 `ROUND_HALF_UP` 保留两位小数。领星登记数值不表示系统已进行现场称重或测量。

在发票“单票资料 → 逐箱制单资料”中按内部箱 ID 修改 PO、毛重及长宽高，页面并列展示自动来源与最终采用值。人工输入按 KG/CM 解释，只影响当前单据，不回写领星或 M2；保留自动来源原值和不可变单据修订。“恢复自动值”移除该箱 PO、毛重和长宽高的人工覆盖，之后须保存资料修订。显式清空表示缺值，生成前必须补齐，不会悄悄回退领星值。

草稿允许缺项保存；生成时每个实际箱必须具备有效 PO、正数毛重和长宽高。缺值、非正数、未知来源单位、无法安全写入 XLSX 的数值均阻塞生成，允许通过本票人工填写有效值补齐。箱身份或商品数量问题仍须回 M2 处理，不能靠修改箱规豁免。

重新打开页面读取已保存修订，不重新抓取并覆盖箱规。显式采用更新来源时，保留仍在本票内且内部箱 ID 相同的人工覆盖，去除已移出本票箱的覆盖；服务端拒绝不属于本票的箱覆盖。来源版本变化仍须重新校验，不能直接沿用旧文件复核。

发生版本冲突后重新读取新版，本次未保存的输入会保留，选择“恢复未保存输入”后核对并重新保存。恢复只合并本次改过的字段，未修改的字段继续采用服务器新版；已移除箱的输入不再应用，已生成文件的单据仍须通过更正处理。

发票生成、总重汇总及 M5–M8 使用同一套最终逐箱 PO/KG/CM 数据，箱数和毛重按内部箱 ID 去重。物流模块独立回收的毛重、计费重以及报关模块填写的净重、毛重仍分别保留，不自动覆盖已登记的外部事实。

已生成文件不能原地改写；修改箱数据通过“更正”建立新单据/修订并生成新文件，原文件、确认、来源及复核历史保留。旧票没有新箱源快照时，继续使用其既有 M3 快照；旧 M3 表、接口、确认、XLSX、备份及归档材料保留兼容，不要求新票补做 M3，也不将旧记录自动标为现场已核验。
