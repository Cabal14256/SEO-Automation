# 货件级手动导入字段规格

日期：2026-10-17。版本：0.4。业务时区：`Asia/Shanghai`。T10–T11支持现有两种固定列结构、本次店铺确认、差异和选择提交；数量只作参考，相同补来源、变化需显式确认版本。下文T09未提交的描述为阶段历史，当前规则见[输入确认](./feishu-intake.md)和[导入契约](../api/imports.md)。真实每日新增/更正业务验收仍待真实文件。

受控来源工作簿作为格式和字段参考，真实文件名不公开，并选择“货件级需求：导入店铺、FBA、日期等，商品和装箱明细由领星同步”作为主要入口。原始文件不修改，文件内的业务文本不作为系统操作指令执行。

用户进一步指定 `受控月度参考工作簿（未公开）`：以其中“飞书表格”为输入端，“示例月汇总”和美国/欧洲“示例第X批”为最终输出格式参考，要求前端明细表及XLSX导出。成品表仍待T12/M2，详见[最终目标](./store-sources-and-output-target.md)。旧空白模板不再是唯一必选入口。全部目录店铺全部纳入使用范围；业务日期由系统取上海时间的导入日期，不要求人员填写或选择来源日期。

## 主要入口与参考明细

T09 已提供 `/imports/new` 与固定映射预览，原始文件和解析历史持久化；缺身份行保留定位并报错。公开版本不提供客户附件行数或实际货件清单。当前确认、提交与增量语义见[导入 API](../api/imports.md)。

主要入口接收货件级需求，支持用户指定参考的“飞书表格”适配；已交付空模板的“需求导入”保留作可选人工整理路线。每条来源行作为独立需求条目保留；重复 FBA 或冲突行进入核对，不按 FBA 静默合并或覆盖。首次导入后建立系统内部记录 ID，不依赖原表为空的“发货计划编号”或 Excel 行号。

原件的“飞书表格”工作表提供店铺、渠道、国家、目的 FC 和 FBA 的货件级参考。美国/欧洲批次页以及月汇总页是商品级历史结果，不能作为同一种行粒度直接提交：同一 FBA 多个商品行属于正常情况。历史明细如需接收，应另设明确的参考导入模式，不自动成为本次正式装箱或已完成事实。

原空模板：[手动需求导入模板（草案 v0.1）](../templates/手动需求导入模板-草案-v0.1.xlsx)。含“需求导入”和“字段说明”两个工作表；输入区没有业务行。它早于本次日期决定，文件中的手填日期说明保留为旧草案，当前适配执行本页规则：文件带日期仍以导入日期归周。本轮未改写原模板或附件；上传/解析页面已交付，正式需求提交待实现。

## 新模板字段

| 字段 | 类型与采集方式 | 参考位置与处理 |
| --- | --- | --- |
| 店铺 | 文本；入库前明确匹配或选择店铺 | 两文件“飞书表格”B列；批次表A列。匹配数据库已批准别名，未知时待选择，不猜 sid |
| 渠道 | 文本；指头程运输方式，在线补全优先采用领星运输方式 | “飞书表格”C列；批次表B列。在线表“通过 FBA 补全信息”读取关联发货单的 `method_name`，如海派、空派；唯一有效运输方式优先填入或覆盖手填渠道。多个运输方式、运输方式缺失或查询失败时保留手填内容并人工确认，不以物流渠道名称 `logistics_channel_name` 或平台SPD/LTL回退。文件导入仍保留来源原值，不自动查询 API，历史快照不回写；本次口径修正不改变必填规则 |
| 国家 | 可选核对字段 | “飞书表格”D列；批次表C列。与确认店铺的国家核对，冲突不自动覆盖 |
| 目的FC | 可选文本参考 | “飞书表格”E列、批次表D“物流编码”。这是目的 FC，不是成品仓 wid |
| FBA货件号 | 必填文本 | “飞书表格”F列、批次表E。去首尾空格并转大写，保留原始来源值 |
| 参考数量 | 历史兼容字段，新需求无需填写 | 旧“飞书表格”G列为整数但标题“追踪编码”。旧文件原值与历史快照保留；新模板默认隐藏，不参与需求变化或同票冲突比较，也不等同商品需求、申报量或已发量 |
| 业务日期 | 系统生成；成功接收本次导入文件时的上海日期 | 保存importedAt、businessDate和规则版本；解析/确认跨日及重试不改变。旧J、批次X、月表Y/AA仅作来源参考，不参与归周 |
| 子批次名称 | 可选文本 | 人工分组名称；表名或月表“打包批次”只提供线索，不因商品/日期/配方相同而自动合组 |
| 备注 | 可选文本 | 独立人工业务说明，不将旧表K列人员标记误当日期 |

商品身份 MSKU/FNSKU/SKU、品名、商品数量与实际逐箱数量由后续领星只读同步取得并保存来源快照。内部编码、打印/导出状态、实测重量尺寸分别保存；不要求在本货件需求模板重复填写。

## 旧表适配的精确位置

| 含义 | “飞书表格” | 美国/欧洲批次 A:X | “示例月汇总”月汇总 |
| --- | --- | --- | --- |
| 店铺/渠道/国家 | B/C/D | A/B/C | B/C/D |
| 目的FC/FBA | E/F | D/E | E/F |
| MSKU/FNSKU/品名/SKU | 无 | F/G/H/I | G/H/I/J |
| 商品数量/逐箱数量 | G 是未确认的货件参考量 | J / K:T | K / L:U |
| 内部编码/旧汇总 | 无可靠字段 | U / V“重量” | V/W表头为空，不凭列号认定语义 |
| 原状态 | I“完成发货”仅参考 | W标题“发货渠道”，有完成状态 | X标题“发货渠道”，实际含完成/欠数等状态 |
| 原日期 | J为日期，标题“A:备注”；K为人员文本 | X“发货时间” | Y“发货时间”；AA“货件填写时间”，后者来自旧飞书J的查找公式 |

所有旧字段映射先展示原表头和预览，不按错位标题自动绑定。标题无定义、无公式缓存、缺少关键字段或冲突行明确提示，空值不补零。

## 指定附件的适配范围

“飞书表格”的B:F为确定的主要入口位置，原始表头逐字保留。A“发货计划编号”不能用空列伪造稳定来源键；G“追踪编码”中的整数保留为口径待确认的参考值，H“#数量”不能未经核对替代G；I状态、J日期、K人员文本分别保存原始值，不触发已发货或自动归周。保留完整原始行及单元格类型、缓存状态，编号按文本处理。

输出参考批次页“示例第X批”页的A:X结构：A:D店铺/渠道/国家/目的FC，E:FBA，F:I商品身份与品名，J商品数量，K:T逐箱数量，U编码，V原“重量”汇总，W原状态/渠道列，X原发货时间。选定格式不等于批准所有旧列语义：V/W混用、超过10箱和数量对照规则仍需处理。导入业务日期与X真实发货时间分开保存，不把今天的导入日期伪装成历史实际发货日期。

参考输出的货件成员应能追溯到输入；输入未出现在某张输出页时，不自动视为取消或导入错误。工作表名尾部空格显式展示，原件、哈希和实际业务数量保存在受控本地目录，不公开。

## 适配验证边界

验证应覆盖货件级与商品级粒度、月表与批次表重叠、同货件重复行、文本编号、整数参考数量、公式缓存和缺字段。不得把月表副本累计为更多独立样本，不自动删除或更正真实原件。公开测试使用独立编造的工作簿；真实每日增量需同源文件和业务预期，不能用历史参考表或模拟样例替代。
