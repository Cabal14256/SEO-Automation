# 近期更新摘要（2026-10-31）

范围：相对 `4a93ef8` 的本地更新，重点为发货、导入工作台与发票单据的表格迁移及读取性能。日期按 `Asia/Shanghai` 记录。本文不代表本轮 GitHub 推送或 VPS 部署已经完成，实际发布结果另以发布收据记录。

## 表格与工作台

- **虚拟表格**：新增 `@visactor/vtable@1.26.8`，发货货件、商品、逐箱视图及其来源、历史、导出等辅助表迁为 Canvas 网格；发票侧覆盖记录、候选货件、逐箱资料、来源、申报数量、任务、文件、修订及复核历史九类表格。绘图库按需加载，其他工作区继续使用原表格。
- **查看与选择**：FBA、批次、目的仓、店铺、国家、渠道拆列显示；货件和逐箱分组支持全部展开／收起。列设置支持搜索、显隐、宽度调整和恢复默认；功能列及关键身份列固定保留。底部提供行定位、查看／操作、详情及分页，支持鼠标中键横向拖动。
- **本地偏好**：列显隐、宽度与每页 20／50／100 条按账号、视图或表格标识保存在当前浏览器，配置包含版本和校验；不保存业务记录、筛选值或选择记录。发货继续按完整货件分页，保留跨页选择；单据主表继续使用现有服务端分页。
- **导入工作台布局**：发货记录与票号改由按钮打开浮窗，导入、导入记录及草稿入口保留；批次范围、选择、安排和展示方式集中到工具栏，过滤条件默认收起并显示已应用数量及未应用修改提示。批次选择器保留搜索、分页、新建和生命周期操作，窄屏浮层限制在可用空间内。

## 发票编辑与操作

逐箱资料按稳定需求 ID 分组，桌面使用单元格输入，窄屏保留当前箱的五字段与前后箱编辑。支持 Enter／F2、Tab、Esc 和中文输入法；保存、筛选、收起分组或切换前完成当前编辑。校验定位会先展开目标组、清除本地筛选并恢复目标列，再定位具体箱和字段；过期定位可撤销，避免关闭向导后抢占焦点。

行内菜单和底部入口提供现有操作与完整详情；自动任务改为独立浮窗。操作弹窗持有者独立于菜单和详情，保留文件下载、任务删除、已有任务恢复、提交锁定及失败反馈。公共弹窗组件统一实现嵌套窗口和滚动锁定。

四步向导、商品／地址／图片表单、固定申报单价、独立 Excel 的 ZIP 打包规则，以及修改原因、人工覆盖确认、恢复自动值、版本冲突、幂等重试和离开保护沿用既有协议。已有文件和历史修订不因表格迁移被改写；本轮没有新增公式、拖填或全库列头筛选。

## 后端读取性能与缓存

发货投影为确认、成员、快照、修订和商品箱分布建立请求内索引，复用校验结果；先计算筛选和统计，再为当前页物化完整箱数据。来源只对当前页需求补全，SQL 只提取所需填写日期。

单据列表使用同事务 `DocumentReadContext`，复用确认组、来源候选、资料／模板版本及归档文件校验。缓存按身份、版本、哈希区分，仅限当前读取请求；并发读取合并，失败也不跨请求保留，权威写入继续执行原检查。指定发货次／月读取不再扫描无关周批次，单票校验只展开目标货件，自动任务列表只选择序列化所需列。

HTTP API、DTO、数据库结构和业务写入协议保持兼容，**本轮没有新增数据库迁移**。部署需按更新后的锁文件安装依赖，并重新构建前端、API 与 Worker。
