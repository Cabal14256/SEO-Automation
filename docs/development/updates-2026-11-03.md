# 近期更新（2026-11-03）

## 本次发布

- 发货导入的运输方式改为手工填写，在线表格与文件解析统一识别 HY／HP／KP／KD／TY／KH，分别归一为海运、海派、空派、快递、铁运、卡航；其他文本保留。
- FBA 补全仅查询店铺、国家、目的仓、地址和创建时间，不再读取关联发货单或覆盖手填运输方式。历史查询中的渠道结果不再回放到新输入。
- 自动整理要求运输方式非空；仅导入需求仍允许留空。查询阶段显式重试会刷新已结束的查询，保留正在执行的查询及原 FBA 分组，避免重试后检查点错配。
- 调整在线粘贴、字段提示、解析版本及回归用例，并更新导入、发货整理和领星集成说明。
- 补充报关资料只读验证记录；M7 仍处于待维护状态。

本次为代码更新，无新增数据库迁移。发票服务映射设置继续使用独立的领星运输方式目录。
