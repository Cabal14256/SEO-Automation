# 近期更新（2026-11-03）

## 本次发布

- 新增“设置 → 店铺导出代号”：按店铺 SID 保存最多 20 位数字，保留前导零；留空恢复店铺名称。新生成的单票发票及整批 ZIP 内文件使用该代号，已归档文件保留原名；包含权限、版本冲突、幂等与审计校验。
- 发票资料选择改为展示商品名称、SKU 和资料版本；唯一且完整的商品资料不再要求重复确认，实质字段变化、多个候选及停用资料仍需明确选择。
- 箱内 SKU 缺失时，仅从身份一致且无歧义的货件商品详情补全；商品资料缺项可由一致来源补齐，冲突值不自动采用。
- 补充报关七页文件的目标取值规则和待确认映射；M7 保持待维护，规则文档不代表功能已上线。
- 本轮新增迁移 `0025_pink_jack_flag.sql`，创建店铺导出代号表，不预填生产代号。

## 当日较早发布

- 发货导入的运输方式改为手工填写，在线表格与文件解析统一识别 HY／HP／KP／KD／TY／KH，分别归一为海运、海派、空派、快递、铁运、卡航；其他文本保留。
- FBA 补全仅查询店铺、国家、目的仓、地址和创建时间，不再读取关联发货单或覆盖手填运输方式。历史查询中的渠道结果不再回放到新输入。
- 自动整理要求运输方式非空；仅导入需求仍允许留空。查询阶段显式重试会刷新已结束的查询，保留正在执行的查询及原 FBA 分组，避免重试后检查点错配。
- 调整在线粘贴、字段提示、解析版本及回归用例，并更新导入、发货整理和领星集成说明。
- 补充报关资料只读验证记录；M7 仍处于待维护状态。

当日较早的运输方式更新没有新增数据库迁移。发票服务映射设置继续使用独立的领星运输方式目录。
