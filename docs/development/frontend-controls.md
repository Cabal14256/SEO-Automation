# 日期与筛选控件

## 发货生命周期交互（2026-10-28）

发货记录、批次和单条需求共用 `ShippingLifecycleActions`：当前记录提供取消／删除，已取消记录提供恢复／删除，回收站记录提供恢复／彻底删除。生命周期独立于处理中、已确认或已冻结状态；冻结记录的普通编辑限制保留，本地作废通过影响弹窗办理。

弹窗先读取最新版本和影响令牌，展示 FBA、批次、发货记录、单据、后续业务及阻塞／冲突，原因必填并明确勾选核对后才提交。网络结果未知时锁定原请求内容，以账号、目标和动作保存在当前浏览器会话中；“待核对操作”可重放，刷新仍沿用相同操作号。409 等已知冲突保留原因，使用“重新核对影响范围”读取最新数据并重新勾选，不把旧令牌自动换入未决请求。

“回收站”按发货记录／批次／需求切换，搜索点击或回车生效并回到第一页；删除原因、时间、待停止状态及恢复／彻底删除入口并列。记录长期保留，无自动清空。恢复冲突整次阻止并定位，彻底删除前显示不可恢复提示及保护原因。操作完成刷新发货、需求、批次、报表、单据、后续工作流和回收站查询缓存。验收入口为 `node scripts/t41/shipping-lifecycle-browser.mjs`，结果以本次报告为准。

## 日期、筛选与业务控件

2026-10-23：实物箱确认入口已移除，旧 physical 深链接转入发票与单据。下文涉及独立实物表/采集的规则仅保留历史兼容说明。当前发票在“单票资料 → 逐箱制单资料”并列展示自动来源与采用值，按箱编辑 PO、KG 毛重和 CM 长宽高；“恢复自动值”移除整箱覆盖，仍须保存资料修订。

前端沿用现有配色和尺寸，按 shadcn/ui 的组件组合方式封装共享控件：Radix Popover / Select、cmdk、React DayPicker。组件位于 `apps/web/src/components/ui`，样式集中在 `controls.css`。

| 控件 | 用途 | 传入值 |
|---|---|---|
| `SelectField` | 状态、映射模式、核对结果等少量固定选项 | 原业务字符串，支持空字符串选项 |
| `Combobox` | 店铺、周范围、FBA、来源等动态列表 | 原 ID 或业务值；`keywords` 补充名称、sid、日期搜索 |
| `MultiSelect` | 需连续或批量选择的货件范围 | 已选 ID 数组与搜索词受控；搜索结果可批量勾选，弹层不因勾选而关闭 |
| `MonthPicker` | 业务月份 | `YYYY-MM` 或空字符串 |
| `DatePicker` | 实际发货日期 | `YYYY-MM-DD` 或空字符串 |
| `DateRangePicker` | FBA 查询、同步和实物采集 | `startValue` / `endValue`，保持接口原有日期规则 |

筛选栏保持“修改草稿 → 点击筛选 → 查询”，重置同时清空草稿和已应用条件。成品表导出仍绑定已应用条件与确认版本。

需求与批次侧栏提供独立的“批次名称 / FBA”搜索，回车或搜索按钮生效，搜索及清空返回批次第一页；沿用共享月份、周、店铺、国家和渠道条件，不修改右侧需求关键词或选中批次。继续处理统一使用选中批次内的入口，处理向导仍保留进度恢复。

发货工作台统一使用“新增需求”入口，直接打开“填写与解析 → 核对与提交 → 导入结果”三步向导。“表格导入”按钮打开二层弹窗，取消或上传失败保留在线输入，文件接收成功后回到第一步核对解析。在线“补全并解析”按每批最多 100 个不同 FBA 顺序查询，最多保留 1000 行；未查到、查询失败或字段冲突时暂停，用户纠正或明确选择“按当前填写继续”后由同一按钮解析。店铺按可信 FBA 查询证据或已批准名称／别名唯一匹配自动采用，仅异常项在第一步处理；未解决行保留错误，有效项可继续提交。源行核对后生成差异，正式需求仍需明确选择并提交。草稿兼容原五步编号：1／2／3 对应第一步，4 对应核对，5 对应结果；失效预览返回第一步。

工作台展示方式位于搜索右侧，立即切换货件、商品或逐箱视图，不应用尚未提交的筛选条件。筛选／重置及完整操作栏位于筛选区第三行；窄屏按阅读顺序换行。操作按钮使用 `type="button"`，仅筛选按钮提交筛选表单。

“查看需求／编辑需求”与需求生命周期操作按完整货件显示一套，商品／逐箱视图不重复每行操作；详情总是读取当前版本和服务端操作权限，不使用冻结旧展示行覆盖。普通编辑保留原因、未保存输入保护和冲突核对；生命周期操作按页首统一弹窗办理。记录筛选区分当前和已取消，已删除记录通过回收站处理；变更记录状态清空原导出选择。已取消／删除记录不能安排批次或导出。

成品表与实物箱确认通过表格首列复选框选择完整子批次，初始空选，跨页保留；同组商品／箱行联动，表头仅全选当前展示行的可导出组并支持半选。应用筛选、重置或切换批次上下文会清空选择。操作栏显示总选择数并提供清空，最多 500 组，超限选择整体拒绝；版本失效取消对应选择，导出版本冲突清空并刷新，网络或队列错误保留范围及重试操作号。实物 XLSX 生成及生成记录入口位于筛选下方操作栏，单组详情保留当前组导出。

发票与单据使用与批次处理一致的四步原生弹窗向导：货件与来源、单票资料、校验与生成、文件与复核。步骤切换保留表单实例，暂时关闭可继续当前输入；刷新恢复已保存单据的步骤并重新读取版本。生成、保存及人工复核均需显式操作，导航本身不发送业务写入。所有日期、地址簿及选择菜单挂载到当前原生弹窗，避免被顶层窗口遮挡。

“货件与来源”中的“查找货件”使用搜索多选下拉，按 FBA、店铺、目的仓、制表组等查找；弹层内可连续勾选多个货件而不关闭，并可全选或取消当前搜索命中项、清空全部已选。下拉勾选与表格勾选共享出单范围，切换搜索保留其他货件的选择。“完成选择”、Escape 或点外部仅关闭弹层，不撤销勾选。搜索同时筛选下方列表，收起后仍显示关键词及“清除搜索”入口；清除搜索恢复全部候选，不清空已选。重新读取其他发货次时清空原搜索和选择。底部统一使用“下一步：预览出单范围”，候选未读取、加载中、失败或未选择有效货件时禁用；预览始终使用全部已选货件，不受当前搜索限制，核对分票后仍明确为所需范围保存草稿。返回调整范围和暂时关闭保留当前选择。

单据记录提供关键词、状态、来源周筛选，回车或搜索生效，搜索与重置返回第一页，服务端先筛选后分页。默认只展示当前单据；已取消和被替代记录可按状态查询。列表提供查看、草稿编辑、已生成单据更正及删除入口。删除须填写原因，沿用取消语义保留历史并释放货件占用；生成中不可删除。网络失败保留原因与原操作号，版本冲突须重新读取目标并核对后再提交。删除当前继续中的单据前保护未保存输入，成功后清理其继续入口。

领星读数动作统一使用 `LingxingProgress`：店铺目录同步、FBA 信息补全、批次货件同步、实物货件采集和单据资料查询。批次及实物采集按服务端任务中已成功／失败的票数计算处理百分比，并分别展示成功、失败数；请求预算只表示消耗。其余动作没有实时总量，等待时使用不定进度条与已用时间，响应结束后显示完成或失败，不推算百分比。部分成功的 100% 表示本轮处理结束，仍需核对失败项。失败后停止动画，保留原有错误、数据与重试机制。进度条提供可访问名称、数值／状态说明，并遵循减少动态效果设置；计时不逐秒触发读屏播报。

日期支持手动输入和日历选择。无效输入保留并提示；必填、日期先后关系在提交前校验。今天、最近 7 / 30 天和本月按上海业务日期计算。本月表示完整自然月。

- FBA 查询包含结束当天；同一天起止有效。
- 同步和实物采集设置 `endExclusive`，接口结束日期不包含当天。日历选择最后一天后，控件自动提交次日作为结束边界。
- 日期范围只在完成两次选择后更新输入；中途按 Escape 保留原范围。
- 周选择只使用服务端返回的可用批次和周起始日期，保留 UUID / weekStartDate，不能用任意日历日期替代。

浮层挂载到最近的原生 `dialog`，避免被顶层弹窗遮挡；Escape 先关闭浮层并恢复焦点。共享禁用状态观察器会跟随现有祖先 `fieldset` 的锁定状态，关闭已展开的浮层。窄屏和矮屏使用碰撞定位及可滚动面板。
