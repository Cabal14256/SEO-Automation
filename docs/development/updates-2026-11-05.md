# 近期更新（2026-11-05）

## 本轮发布

- 欧洲发货表在每个 FBA 内，按商品首个和末个有货箱序排列，相同箱序保留来源顺序，方便沿箱列逐项核对。
- 页面预览与 XLSX 统一显示“内部编码”：按商品所在箱的正数量分配列出真实箱码，例如 `H1H2`。只有美国整票所有实际箱的商品身份及数量完全一致时，才在首行显示整票编码范围；完整逐箱数据参与判断，分页不改变结论。
- 发货表模板升级为 `shipment-record-v10`，保留十箱基准、动态扩列、票间空行和逐箱明细；历史文件保留原件。
- 整理最终交付范围与负责人已确认的人工验证状态：仅交付发货工作台、发票与单据及配套设置；范围外功能保留历史追溯，不再列为开发待办。
- 移除仓库根目录的旧领星代理启动快捷脚本。

本轮无新增数据库迁移，生产依赖不变。部署与技术检查结果以对应发布记录为准。
